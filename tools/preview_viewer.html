Skill preview viewer

  1. Find skills to check: set Show to "Needs attention" for skills whose shape the mod cannot read yet, or browse everything.
  2. Compare each drawing with the game. Move the mouse over a drawing to aim, like in a match. The level slider changes ranges that grow with level.
  3. If a drawing is wrong or missing, pick a Preview type. Its boxes fill in from the game's own numbers for that skill (the field each came from is shown beside it); correct them if needed. "Use suggestion" applies the viewer's guess.
  4. Click Save. Your choices go into the mod's folder and apply the next time the game starts.
  5. Tick Checked by me on each skill once its drawing matches the game; ticks save at once. "Show: Not checked yet" lists what is left, and the header counts your progress. Changing a skill's assignment clears its tick, since it needs checking again.

The cast range always comes live from the game (it follows level and balance patches), so assignments hold only the shape. An empty length means "the whole cast range". An assignment wins over everything the game reads for that skill.

When the game already reads part of a skill (for example a blast around the caster) and only part is missing (for example a jump away), choose Add to what the game reads: your shape is drawn on top instead of replacing the read one. Each drawing zooms to fit its skill; the scale bar shows 25 units, and "Same scale" compares sizes between skills.

Values are filled in from what the viewer learned: for every skill the game reads, it finds which of that skill's numbers holds each size, and tries those fields first for skills it cannot read. When a number is not in the game's data at all, the box says so and the value is yours to enter.
