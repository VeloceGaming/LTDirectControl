How to use

  1. Find a skill. Move over its drawing to aim; scroll to zoom. Level changes ranges that grow with level.
  2. Compare with the game. Each card has two parts: Cast, how the game aims the skill (from the game, not editable), and What it hits: what the game reads, your pieces, or nothing. Edit (the gear) shows both and holds your pieces; the panel also has Numbers and Details. Filter by Cast and Hits.
  3. Save writes assignments for the next game start. Checked marks and size-source picks save automatically.
  4. Tick Checked by me after comparison. Editing a shape clears its check.

Cast range follows the game and level. Empty length uses the cast range. Assignments replace the read shape; Add to what the game reads keeps both.

Custom (pieces): build a preview from blocks (circle, line, shot, dash and more). Each size is a typed number, a game number (times a factor), two game numbers multiplied, or the cast range. The mod draws it exactly as listed. Edit it under Pieces; Save, then restart the game to try it.

Size sources: a named game value follows edits and patches; fixed values do not. Pick the correct source when two values fit. Missing numbers need a recorded match; background matches count.

How values are suggested

The viewer learns which named game values match recorded shapes and tries those fields first. Missing values must be entered manually. Suggestions are guesses until you compare them with the game.
